# 🏛️ SANGYAN KAVACH (संज्ञान कवच)
## India’s AI-Powered Investor Safety & Financial Deception Defense Layer
*A National Public-Good Initiative for Bharat's Retail Investors*

**Organizers:** Securities and Exchange Board of India (SEBI) × National Securities Depository Limited (NSDL) × Science & Technology Council, IIT (BHU) Varanasi  
**Competition:** SANGYAN Investor Resilience Hackathon (October 2026)

## 🏆 Hackathon Track Alignment

* **Primary Track:** 🟥 **Track A — Digital Fraud & Scam Resilience**  
  *Detecting, warning against, and intercepting deceptive financial vectors BEFORE money changes hands.*
* **Supporting Track 1:** 🟪 **Track E — Misinformation & Financial Content Literacy**  
  *Promotion vs Education classification, deconstructing psychological coercion, and non-binary evidence calibration.*
* **Supporting Track 2:** 🟨 **Track C — Investor Education for Bharat**  
  *Regional voice explainer (Hindi Audio), vernacular analogies (rural & semi-urban metaphors), and fraud-mechanics simulation.*

- Node.js (v18+)

### Installation & Run
```bash

npm install

# Run development server (accessible at http://localhost:3000)
npm run dev

# Run production build & preview
npm run build
```

## 🎯 4 Instant Jury Demo Presets (Test in <10 seconds)

1. **Preset 1 (Track A): Telegram VIP Upper-Circuit Scheme**
   * *Claim:* "Prof. Rajesh Sharma (Reg: INA998877112) Guaranteed 300% profit in 48 hours on SME IPO! Transfer ₹25,000 to personal UPI."
   * *Result:* Flagged as **Critical Scam Risk (96/100)** due to invalid registration checksum, guaranteed return promise, and personal UPI request.
2. **Preset 2 (Track A/E): Cloned Broker Demat Phishing**
   * *Claim:* "Urgent: Zerodha Demat blocked. Verify Re-KYC at https://zerodha-rekyc-update.vip within 2 hours."
   * *Result:* Flagged as **Critical Risk** due to lookalike domain targeting Zerodha and credential harvesting threat.
3. **Preset 3 (Track A/C): Fake SEBI Certificate PMS Scheme**
   * *Claim:* "SEBI Guaranteed Portfolio Manager INP887766554. 40% monthly interest guaranteed under Special Window Circular."
   * *Result:* Flagged as **Critical Risk** due to illegal regulatory impersonation and fictitious circular.
4. **Preset 4 (Negative Control): Genuine SEBI Investor Awareness**
   * *Claim:* "SEBI Investor Awareness: Understanding Index Funds and Market Volatility. Past performance does not guarantee future results."
   * *Result:* Correctly recognized as **Low Risk (08/100) — Balanced / Educational**, proving zero false alarms on legitimate education.
